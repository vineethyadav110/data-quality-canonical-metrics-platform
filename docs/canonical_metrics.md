| Metric               | Definition                                     |
| -------------------- | ---------------------------------------------- |
| Total Trips          | Count of valid analytical trip records         |
| Completed Trips      | Trips where `delivery_status = completed`      |
| Completion Rate      | Completed Trips / Total Trips                  |
| Cancelled Trips      | Trips where `delivery_status = cancelled`      |
| Average Duration     | Average duration of valid trips                |
| Average Distance     | Average distance of valid trips                |
| Total Distance       | Sum of valid trip distances                    |
| Total Revenue        | Sum of valid trip fares                        |
| Revenue per Mile     | Total Revenue / Total Distance                 |
| Active Vehicles      | Distinct vehicles participating in valid trips |
| Quality Failure Rate | Failed raw records / raw records               |
